# Zomato Restaurant Analysis Dashboard \| Power BI

An interactive **Zomato Restaurant Analysis Dashboard** built in
Microsoft Power BI. The report presents restaurant data through summary
cards, charts, maps, and interactive slicers.

## Dashboard Screenshots

### 1. Overview

![Zomato Dashboard --- Overview](screenshots/zomato-overview.png)

The Overview page summarizes restaurant coverage across countries,
cities, restaurants, and cuisines. It also includes table-booking
analysis, restaurant distribution by country, top cuisines, and top
restaurants.

### 2. Restaurant Analysis

![Zomato Dashboard --- Restaurant
Analysis](screenshots/zomato-analysis.png)

The Analysis page explores restaurant ratings, votes by restaurant,
cuisine distribution, and restaurant addresses. Slicers allow users to
filter the report by rating color, city, online delivery, and table
booking.

## Project Objective

To explore Zomato restaurant data and present useful patterns in an
easy-to-understand, interactive Power BI report.

## Tools Used

-   **Microsoft Power BI Desktop** --- report building and data
    visualization
-   **Power Query** --- data preparation and transformation, where used
-   **DAX** --- measures and calculations, where used

## Dashboard Features

-   KPI cards for countries, cities, restaurants, and cuisines
-   Table-booking breakdown
-   Restaurant count by country shown on a map
-   Top 10 cuisines and top 10 restaurants
-   Restaurant rating-color distribution
-   Votes by restaurant visualization
-   Cuisine treemap and address list
-   Interactive slicers and page navigation

## How to View the Project

1.  Download the `.pbix` report file from this repository.
2.  Open it in **Microsoft Power BI Desktop**.
3.  Use the slicers and page navigation to explore the report.
